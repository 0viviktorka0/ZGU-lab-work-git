# Проект ZGU-lab-work-git

## 📌 Краткое описание
Этот проект создан в рамках выполнения Лабораторной работы №2. Он демонстрирует навыки работы с системой контроля версий Git, удаленными репозиториями GitHub, ветками, разрешением конфликтов и релизами.

## ⚙️ Установка и запуск
Для запуска проекта вам понадобится установленный Python.
1. Скачайте репозиторий на свой компьютер.
2. Перейдите в папку с проектом.
3. Запустите скрипт с помощью команды:
   `python src/main.py`

## 🚀 Основные функции
*   Вывод приветствия (`print("Hello, Git!")`).
*   Функция сложения двух чисел (`add(a, b)`).
*   Функция умножения двух чисел (`multiply(a, b)`).
